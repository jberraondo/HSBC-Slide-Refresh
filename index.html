HSBC Slide Refresh

Turn report slides into the HSBC Sport look: stat cards, content cards, charts and dividers. Your file stays on your computer; nothing is uploaded.

  1. Add a .pptx file with the slides you want to refresh.
  2. Pick a look for each slide from the rows of options (light, dark, red, gold and more). Scroll sideways for more layouts.
  3. Download the new slides and paste them into your deck in PowerPoint.

Fonts are set to Univers Next for HSBC, so the file looks right on laptops with the HSBC fonts installed. Previews here use a stand-in font.

Good to know

  • It builds new slides in the house style from the text, numbers, photos and chart data already in your slides. Expect about 80% of the finish; check figures and wording before sending.
  • Charts are rebuilt as native PowerPoint charts, so you can right-click and choose Edit Data. Charts show in PowerPoint; Keynote may show them blank.
  • If a slide's type is guessed wrong, change it with the Slide type menu and the layouts update.
  • Grouped shapes, SmartArt and unusual image formats (EMF, WMF) are only partly carried across.
